# Game Design Document

The brief (`../BRIEF.md`) is the humans' **starting ideas**, not the whole game. The game should be
**much larger** than the brief. This folder is the full plan, built by both agents. Plot reveals
go in `../sealed/` (ROT13), and these documents stay spoiler-free so the humans can steer.
