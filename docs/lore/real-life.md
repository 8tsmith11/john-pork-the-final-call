# Real-life lore

The three of us are real people, and the game should be full of things only we would recognize.
This file is the source for that: true stories, running jokes, objects and places from our actual
lives, written down so every agent can draw on them for story, items, NPCs, barks and easter eggs.

**How to use it.** Agents add what their own human tells them, with their permission and credited
(*Michael says: ...*). Draw from any entry, but bend it into the world of 2098; don't copy it
straight in. A real-life story used as a surprise for the others goes into the game sealed, like any
spoiler (see `PROCESS.md`).

## Shared

- **The hidden-object war.** We used to hide objects in each other's stuff: bags, closets, shoes,
  wherever it would be found at the worst moment. Two of the objects:
  - **The meat stick.** Yes, an actual meat stick. It got hidden in each other's things over and
    over. *(Michael)*
  - **The balloon.** The balloon was one of these objects too, which is part of why it matters so
    much in the game. *(Michael)*
  - **The purple cylinder.** A purple object cast in silicone, shaped like you would guess. It gets
    hidden around the apartment like the others. In the game it is only ever a plain purple
    cylinder and the joke is how people react to finding it (D-015: nothing graphic is drawn).
    *(Manuel)*
- **"You're absolutely right to point that out."** We say it to each other, deadpan, to mimic how an
  AI answers. It works best right after someone states the obvious or catches a mistake. *(Manuel)*
- **The smart pacifier.** Michael and Manuel are developing a smart pacifier for a children's
  hospital. They hold a patent on it, and they work on it in the apartment. *(Michael)*
- **The 3D printer and Juan el Porko.** They got a new 3D printer and mostly use it to print John
  Pork figurines. That's what led the roommates (the "goonmates") to get a John Pork flag, and now
  everything in the apartment centers around Juan el Porko. *(Michael)*
- **Room 631, ASTER, College Park, "Aster pros," "rookie Aster mistake," 245 lab, the John Pork
  flag and statues:** these come from the brief (`docs/BRIEF.md` §3 and the appendix).

## Ideas this file suggests (agents, take or leave)

- The meat stick as a **recurring hidden object** that keeps turning up in a different roommate's
  stuff each act (a container, a coat pocket, the fridge), with a tally somewhere of who has found it.
- The purple cylinder as a **findable that moves**: it is in a different container each time a save
  is loaded (seeded loot tables can do this), and whoever finds it gets one deadpan line and can
  hide it again in any searchable container for the next player.
- Balloon gags that echo the real war: balloons turning up where they shouldn't.
