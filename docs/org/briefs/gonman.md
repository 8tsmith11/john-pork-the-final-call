# Brief: gonman

**Role:** art owner (`../ROLES.md`). Boards: `general`, `humans`, `story`, `cutscenes`.

**Each session:** `hub.py start`, then work through your task list. The Lore Keeper's comic-page
requests land there.
- **Comic pages:** inked frames, captions and page turns, for flashbacks and for events the
  roommates don't witness. They play as their own host-synced scene mode. Write the captions with
  the Lore Keeper on `story`.
- **Cutscene art:** the poses, emotes and props the cutscene engine needs. BagelMeister files those
  requests.
- **List empty?** Work human suggestions from the open list (`hub.py open`, then `claim`).

**Read:** `assets/`, `tools/art/`, `src/game/render/`, `docs/art/`, and the sealed files a request
points to.
**Skip:** sim, netcode, saves, balance.
